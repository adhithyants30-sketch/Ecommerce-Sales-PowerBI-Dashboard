# 🛒 E-Commerce Sales & Customer Analysis Dashboard

An interactive **Power BI dashboard** designed to analyze e-commerce sales performance, customer behavior, profitability, payment methods, customer segments, and regional sales.

This project provides a visual overview of important business KPIs and helps identify sales and customer trends through interactive charts and filters.

## 🎯 Project Objective

The objective of this project is to create an interactive Power BI dashboard that provides insights into:

- Sales performance
- Profitability
- Customer activity
- Order trends
- Average Order Value
- Payment methods
- Customer segments
- Regional sales performance
- Top customers

## 📈 Dashboard Features

### 1. Monthly Sales Trend
A line chart showing monthly sales performance and changes over time.

### 2. Top 10 Customers
Displays the top customers based on:

- Total Orders
- Total Sales
- Total Profit

### 3. Payment Mode Analysis
Visualizes sales/order distribution across different payment methods such as:

- UPI
- Credit Card
- Debit Card
- Net Banking
- Cash on Delivery

### 4. Sales by Customer Segment
Analyzes sales contribution from different customer segments:

- Consumer
- Corporate
- Home Office

### 5. Sales by Region
Compares sales performance across different regions:

- South
- East
- North
- West

### 6. Interactive Filters

Users can filter the dashboard using:

- Month
- Region
- Category
- Payment Mode
